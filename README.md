# CNC Tool Manager

A web-based tool inventory management application designed to help industrial teams monitor tool stock, record stock movements, and identify tools that need replenishment.

## About the Project

CNC Tool Manager aims to simplify inventory management in a CNC machining environment by replacing manual stock records with a centralized digital system.

The project is inspired by real-world industrial workflows, where accurate stock information is essential to prevent shortages and support daily operations.

## Project Goals

- Keep tool inventory organized and easy to access.
- Monitor stock levels and identify tools that require replenishment.
- Record incoming and outgoing stock movements.
- Verify physical inventory and correct stock discrepancies.
- Manage tool categories dynamically.
- Provide a responsive interface for desktop and mobile devices.

## Planned Features

- **Dashboard:** Overview of total tools, total stock, low-stock items, and out-of-stock items.
- **Tool Management:** Add, search, filter, edit, and remove tools.
- **Stock Monitoring:** Define stock thresholds and identify tools that need replenishment.
- **Stock Movements:** Register incoming and outgoing quantities while preventing invalid stock deductions.
- **Stock Verification:** Compare recorded quantities with physical stock and confirm corrections.
- **Category Management:** Create and manage tool categories without modifying the source code.
- **Movement History:** Keep a record of inventory transactions.
- **Responsive Design:** Adapt the interface to desktop and mobile screens.

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using a local development server, such as the Live Server extension.
4. Continue development by working on the CSS and JavaScript files.
